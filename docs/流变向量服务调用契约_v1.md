> contract-version: 1.1（2026-10-01，记忆向量复核后修订：维度口径/超长行为/重试标注三处）
> 目的：把向量服务的调用行为固化成文档，供流变家族各插件对齐。基建抽不抽、插件归属怎么变，本契约描述的服务事实不变。
> 素材来源：流变·博物（dsh-liubian-museum）与流变·记忆（dsh-liubian）的实测调用行为；v1.1 修订经记忆向量对照服务端启动参数与 semantic_search.py 源码复核。

## 2. 端点契约

### 2.1 探活：`GET /health`
- 200 = 在线；任何异常（超时/连接拒绝）一律折算为"离线"，**消费方不得因探活失败报错中断业务**。
- 探活超时建议 3s。

### 2.2 向量化：`POST /v1/embeddings`（OpenAI 兼容）
- 请求体：`{"input": ["text1", "text2", ...], "model": "qwen3-emb"}`
- 响应：`data[].embedding`（float 数组），**按 `data[].index` 排序后使用**（服务端当前版本实测保序，但契约层面不依赖保序——记忆侧待对齐项①，见 §7）。
- **维度**：当前家族统一 **1024 维**（EMBED_DIM=1024 已钉死于记忆侧常量与 embeddings 表结构）。**换模型 = 全量重嵌 + embeddings 表重建**，属高成本迁移，慎行——不要轻率更换嵌入模型。
- 批量：**单请求 ≤64 条**（博物实测安全值；受单请求槽限制，贪大只会排队）；单请求超时建议 90s。

## 3. 已知坑与现存行为差异（消费方对齐项）

| 坑 | 现象 | 现存行为（两种，均已生产验证） |
|---|---|---|
| 空文本 | 空字符串/纯空白输入 → **HTTP 400** | 双方一致：发送前过滤 `text.strip()` 为空的条目 |
| 偶发断连 | `WinError 10054` | **博物**：重试一次（退避 1.5s）再降级；**记忆**：无重试，一次异常直接回退纯 tag。新消费方二选一，推荐带一次重试 |
| 超长文本 | **行为未定义**（疑似服务端静默截断——记忆侧 9456 篇截断嵌入零报错） | 消费方自行处理：**记忆**=截断（日记 600 / 技能索引 1500 字符）；**博物**=切块 1200 字符。新消费方必须选一种并写明 |
| 服务重启窗口 | 看门狗重启期间短暂离线 | **博物**：探活失败重试一次再降级；**记忆**：直接降级（与断连同路） |

## 4. 降级链（消费方对齐项）

| 消费方 | 离线降级行为 |
|---|---|
| 流变·记忆 | 语义检索降级为纯 tag 检索 |
| 流变·博物 | 语义检索降级为文件名/描述/标签 LIKE 匹配 |

**约定**：新消费方接入时必须声明自己的降级行为并写进本表——没有降级链的消费方，在服务离线时会成为全家族的故障放大器。

## 5. 控制面与看门狗（迁移随行项）

- 控制面四操作（status/ensure/stop/restart）与看门狗（私有提交 >4096MB 自动重启，每 300s 检查）属于 embed 插件的**运维资产**——llama-server 有提交内存泄漏前科（实测 5.5h 涨到 10.9GB，重启回落释放 9.2GB），**任何归属变更必须完整随迁看门狗，不能裸奔**（记忆向量提醒在案）。
- 启动方式沿革与泄漏观测方法见 embed 插件源码注释与交接清单。
