# v1.0.0 — 首次开源发布

**流变系统（Liubian）** 首次开源。这是一套给 AI 智能体用的**持久记忆与协作底座**：把每一轮对话沉淀成可检索的日记，让多个智能体互相留言、实时会诊，并让技能在它们之间自动分发与同步。

## 本版内容

**四个子系统**

| 子系统 | 能力 |
|---|---|
| 流变·记忆 memory | 日记写入、标签索引、跨会话检索、语义向量召回 |
| 流变·被炉 kotatsu | 多智能体实时房间：收发、待办、挂机监听 |
| 流变·更新 update | 技能装载 / 快照 / 哈希同步 / 订阅广播 |
| 流变·通路 path | 无上下文双 API 交叉校验（生成 → 五维度挑错） |

**两套接入方式**

- **Codex / MCP 侧**：9 个 MCP 服务器（记忆读写、检索、被炉、更新、技能索引、通路校验、管理面板、嵌入服务、身份守卫）+ 统一 CLI `liubian.py` + 本地管理面板（Web / PyQt）
- **DeepSeek Harness 原生插件**：16 个原生工具，并额外实现
  - **自动日记** —— 每轮对话结束后，由外部 API 把上一轮完整对话写成日记（标签候选用本地向量模型从 13938 个标签里选前 100 个），下一轮自动落库；标签不足 5 个会重试，绝不拿泛标签凑数
  - **联合检索注入** —— 查询 = 上一轮回答 + 本轮问题 → ①嵌入成向量与全库 6114 篇日记算余弦 ②同一段文本 + 标签候选送外部 API 挑 5 个标签做字面检索 ③两路融合取前 10 篇**全文**注入上下文

**设计文档**

- `liubian/设计/流变系统总体设计_v1.md` —— 四子系统分层（接入 / 协议 / 服务 / 存储）、数据流、用户体系、迁移计划

## 环境要求

- Python 3.10+（标准库为主；numpy 可选，缺了自动退化为纯 Python 余弦）
- 可选：本地嵌入服务（llama.cpp `--embeddings`，默认 `http://127.0.0.1:8082`，1024 维）
- 可选：任意 OpenAI 兼容 API（自动日记 / 通路二校验用）
- DSH 插件部分：DeepSeek Harness，Node 20+

## 注意

- 仓库**只含代码、技能定义与设计文档**；日记、向量、日志等运行时数据不在其中。
- 通路二的双 API 密钥请自行填入 `liubian/scripts/通路2/config.json`（参考同目录 `config.example.json`）。
- 记忆数据默认落在单个 SQLite 库，路径由 `LU_DB` 环境变量指定。
