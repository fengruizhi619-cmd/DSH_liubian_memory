## §1 插件骨架

- 入口两层：`main.mjs` 静态导出 name/inject，`apply()` 内以 `impl.mjs?t=<时间戳>` 动态导入实现层——绕开 ESM 按 URL 缓存，改实现层后 uninject+inject 即生效。〔出处：全家现行；检查表 §3.1.2〕
- package.json 声明 `dsh.bundle.patch`（bundle 自装配）+ MIT LICENSE + README；交付走 git 提交推送。〔出处：v4 事故——缺 dsh 元数据的包在 patch 重读时被整批丢弃〕
- ⚠ node_modules junction 指向宿主 checkout（`E:\DSH Desktop\resources\app\node_modules\@deepseek-ai\...`）；Test-Path 对悬空 junction 会报 True，验证解析必须用真实 import。〔出处：2026-10-01 基石 junction 修复〕

## §2 工具注册

- 工具名必须带家族前缀：`_dsh_external_dsh_liubian_<插件>_<动作>`（裸名会撞宿主内置工具被静默遮蔽）。〔出处：liubian 早期工具裸名被 fs 工具遮蔽〕
- `defineTool` 展开时 name/output 置于展开之后（防 def 自带 name 覆盖前缀）。〔出处：检查表 §3.2.1〕
- 控制面动词统一四件套：`status / ensure / stop / restart`（样板：dsh-liubian-embed）；数据操作按业务命名。
- 工具改名/迁移必须在**同一批提交**里登记连带影响方（例：被炉前缀 ↔ 孪生 twinToolWhitelist；embed 控制面 ↔ 记忆技能文案 + status 输出提示）。〔出处：2026-10-01 迁移讨论；注意区分真耦合（被炉前缀=孪生白名单在用）与非耦合（embed 控制面=孪生白名单从未包含）〕

## §3 会话消息构造

- 四要件缺一不可：`id`（uuid）/ `role` / `source.kind`（v4 必须 producer-owned `plugin:<包名>`，裸 `plugin` 被拒收）/ `content`（数组）。〔出处：D0660 历史坑 + 2026-09-26 v4 全家适配〕
- `form=notice` 必带 `summary`；`form` 只用合法值（instructions/catalog/snapshot/notice/relay/recall）。
- 自贡献的 assistant 消息必带 reasoning 块（thinking 模式缺 reasoning_content 回传会被上游 400）。〔出处：2026-09-19 实测事故〕
- **禁止伪造"已总结完毕"的空正文助手尾消息**：线缆实测它会以 `{role:'assistant', content:'（判据已对照完毕…）'}` 上线，模型交白卷或狂思后被 max_completion_tokens 截断。〔出处：2026-09-30 透明代理抓包，监察 0% 事故根因〕

## §4 helper 脚本协议（Python/外部子进程）

- stdin **按字节读**再自行解 UTF-8（Windows ANSI 会吃中文）；stdout `reconfigure(encoding='utf-8')`。
- 配置经 env 传递（`LU_*` 前缀），不进命令行正文（长度/转义双坑）。
- 错误打 stdout JSON `{ok:false,error}`，不抛异常；**写完必须用真解析器自检**（近似判断会漏——空文本归因教训）。
- `execFile` 后显式关闭 stdin（不关则 helper 卡到超时）。〔出处：检查表 §3.4.0〕

## §5 配置与共享键

- 三层合并：DEFAULTS → `~/.dsh/<目录>/config.json`（**剥 BOM**）→ 宿主 input，走 loadConfig 单入口。
- 家族共享键统一进 `~/.dsh/liubian/config.json`，键名与消费方 DEFAULTS 同名（现役五键：python / memoryScript / liubianRoot / workspace / memoryTimeoutMs）。**共享键改名 = 契约变更**，需通报全部登记消费方。
- 优先级序钉死：**共享源 > 宿主入参 > 消费方兜底**；消费方启动日志打印生效值供核对——范围至少覆盖**影响投递与安全行为的键**（全键打印致日志膨胀）。〔出处：2026-10-01 便签↔记忆交接，memoryTimeoutMs 120000 覆盖 180000 的验证即靠这条；范围界定：白泽 2026-10-01〕

## §6 降级链与契约

- 消费外部服务的插件，必须在对应契约声明离线降级行为——没有降级链的消费方是全家族的故障放大器。〔样板：向量契约 v1.2 §4〕
- 服务化接口必须带 `contract-version` 字段；长文本消费方按 **token 预算**自查（字符数估不准 token，实测 12000 汉字仅折 6001 token）。〔出处：向量契约 v1.2 边界补测〕
- 主要版本（语义变更，如 v1→v2）迁移窗口：**两周或一个迭代周期取大者**，窗口内新旧并存（双端点/双前缀）、旧端点不下线不 410；小版本（勘误/措辞）直接换。
- 服务端并发/限流额度有限时，客户端必须串行化（在途时新调用 skip 不排队）+ 限流错误退避加倍。〔出处：2026-09-30 监察 0% 事故——8 路并发 2 个 429〕
- **本族已声明的跨插件消费降级链**（§10 表内每新增一个消费方，此处补一行）：
  - **孪生 → `~/.dsh/liubian/lessons*.json`（只读）**：文件缺失 / 损坏 / BOM 异常一律按空清单处理（`loadLessons` 用 try/catch 吞掉全部异常，且「没有工作区名绝不回落全局文件」有显式守卫）；后果 = 送监指令里「通用教训（对照参考）」整节不出现，**审查照常进行、不报错、闸门不受影响**。教训是**审查材料**而非功能通道，故降级只损失审查精度的上限。〔出处：孪生 `lib/impl.mjs` L1494–1503 / L1516 起；2026-10-01 §10 补登记时同批声明〕

## §7 落盘时机纪律

- **绝不在工具窗口写会话**：assistant 带 tool_calls 到工具结果落盘之间，插入任何消息都会让会话永久非法（上游 400 拒收后续每轮请求）。
- 会话写入必须落在打开的 step 内（token meter 硬约束），写入排队到 step/end 等安全时点执行。
- 旁路备份（jsonl）无条件写——会话写入失败不影响备份完整。〔出处：孪生 appendTwinRecord 现行实现〕

## §8 测试与验收

- **边界行为必须用真实多样化载荷实测**：上游保护会让"没出过错"变成假安全（被上游截断保护的样本永远触不到边界）。〔出处：2026-10-01 向量契约空文本归因被实测推翻——记忆向量认领的证伪〕
