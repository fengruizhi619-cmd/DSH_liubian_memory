### 注册表 schema（0.3.0）

```sql
identities(name PK, name_key UNIQUE, hash UNIQUE, short_id, status, workspace, note, created_at, retired_at, retired_note)
bindings(session_hash PK, name UNIQUE, bound_at, note)      -- 名字副本，改名时同事务传播
session_seen(session_hash PK, workspace, last_seen)         -- 注入钩子登记，bind 归属校验用
meta(k PK, v)
name_aliases(name_key PK, name, hash, renamed_at, note)     -- 0.3.0：旧名 → 身份
renames(id, hash, old_name, new_name, at, actor, note)      -- 0.3.0：改名账目
```

### 动作面

`register / verify / lookup(name|id) / list / rename / retire / attribute / bind / unbind / binding / bindings / status`｜`embed-status / embed-ensure / embed-stop / embed-restart`

### 跨插件服务通道（v0.3.1，被炉账号工具用）

按单写者规矩，写动作由基建落笔、消费方**不直写** `registry.db`：

```js
const svc = ctx.reflect.get('liubianInfra')   // 或 ctx.get('liubianInfra')
svc.version                                       // 1
await svc.rename({ hash, newName, actor, note })  // → {ok, hash, name, shortId, bindingsMoved?, noop?, error?}
await svc.unbind({ sessionHash })                 // → {ok, removed, name?, error?}
```

- `rename` 的 `hash` 也接受**当前名**或 hash 唯一前缀；语义 = 工具面 `rename`（hash 不变 + 别名 + 账目 + 绑定副本传播）。
- `unbind` **只在删除账号时**调用；**退出房间不解绑**（退房 ≠ 销号）。
- 错误一律折成 `{ok:false,error}`，不抛。
- 挂载形态：优先 `ctx.provide`（cordis 标准形），回退 `ctx.reflect.provide`；两者皆无 → 记一条 warn 且服务缺席（消费方应显式报错，不得静默降级为"只改本地名"）。

## 5. 已知坑（上任前必读）

1. **热更姿势按归属选**：bundle 归属插件**不要**用 `uninject + inject`（会写 `disabled` 残留、删 junction）；改 `impl.mjs` 走「touch profile patch 触发重装配」。纯注入包才用 uninject+inject。判据看 profile `dependencies ∩ bundles`。
2. **junction**：用 `_dev/heal-links.mjs`（体检/修复双模式；判据全走解析级：lstat/readlink/realpath + 透过链接真读 package.json）。**指向正确但暂不可读一律只报 SUSPECT、绝不 rm**。junction 缺失的表现是「静默不挂载」。
3. **单写多读**：只有基建写 registry.db；消费方一律只读打开（`mode=ro`）。别用共享 DB 写做跨插件同步（用工具/服务通道）。
4. **改名不变式**：hash 是账号 ID 不可变；name 可变。旧名不可二次注册（hash 由名字派生）。拒绝路径零写入、写入包事务。
5. **看门狗阈值**：本机空载稳态私有提交 ≈10.8GB，**阈值必须显著高于它**（现 12288MB）；阈值低于稳态 = 周期性杀服务 → 每次击杀都是整模 GPU 重载尖峰（2026-10-01 旧 embed 看门狗因此全天击杀 80 次，凌晨无任务也每 5 分钟一次——「没向量任务却跑满 GPU」的根因）。
6. **ensure 防重复拉起**：spawn 前必须查存活进程（`serverPids`），否则同端口多实例抢 8082、每个都是整模载入。
7. **提交与文件的 BOM 坑**：Windows PowerShell 5.1 的 `Set-Content -Encoding UTF8` 会给文件加 BOM；提交信息走 `git commit -m '单引号'` 或 write 工具。**判定提交是否带 BOM 必须看原始字节**（`git cat-file commit <hash>`），`git log --format=%B` 会吃掉 BOM 造成假阴性。
8. **日志 sink**：插件 logger 落 `%APPDATA%\DSH Desktop\logs\host\dsh-<date>.log`（不是 `logs\dsh-*.log`，后者是桌面壳日志）。
